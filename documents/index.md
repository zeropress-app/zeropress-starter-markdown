# My Docs

A home for your documentation, built from Markdown with ZeroPress and the Docs theme.

Start with these pages, then replace them with your own guides, notes, and reference material.

## Explore the examples

| Page | What you will find |
| --- | --- |
| [Getting Started](getting-started.md) | Preview locally, write a page, and publish changes |
| [Markdown](guides/markdown.md) | Titles, frontmatter, source links, and page routes |
| [Markdown Examples](markdown-examples/index.md) | Alerts, tables, code blocks, task lists, and diagrams |
| [Navigation](guides/navigation.md) | Grouped menus, nested links, and reading order |
| [Configuration](guides/configuration.md) | Site settings, search, update dates, and theme files |

## Find your way around

Use the sidebar to browse a section, or open **Search docs** to find a page or heading.
The **On this page** links jump to sections within a document.

At the bottom of a guide, **Previous** and **Next** follow the reading order set
for that group.

> [!TIP]
> Keep links between pages source-relative, such as `[Getting Started](getting-started.md)`.
> The same link works in your editor and becomes a page URL when built.

## Make it yours

Edit the title and navigation in `documents/.zeropress/config.json`.
Styles and templates live in `theme/`.

Continue to [Getting Started](getting-started.md).
