# About this site

This site starts with the ZeroPress Markdown Starter and the Docs theme.

## What is included

The starter turns Markdown files into a static documentation site with sidebar
navigation, search, a table of contents, and previous/next links.

The pages are examples you can edit or replace. Start with the
[Markdown guide](guides/markdown.md), or open the [configuration reference](guides/configuration.md).
